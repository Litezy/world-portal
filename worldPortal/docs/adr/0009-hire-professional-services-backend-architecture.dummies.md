# ADR for Dummies: 0009 - Hire & Professional Services Directory

* **Status:** Approved
* **Date:** 2026-09-13
* **Target Audience:** Non-technical stakeholders, Product Managers, Operations

---

## 1. What problem are we solving?
Currently, the list of hireable professionals (drivers, guides, translators, bodyguards) on the website is static. When a user clicks to hire a professional, the data isn't saved to a real database.

We are building a backend database service to allow travelers to search real professionals, view their ratings and experience, and submit hire booking requests.

## 2. What is changing?
* **For Travelers:** Can filter professionals by country, rating, and service type, and place actual booking requests.
* **For Operations:** Staff can view incoming hiring requests and assign available professionals.

## 3. Key Benefits
* Real-time professional directory and ratings.
* Secure booking storage and review tracking.
