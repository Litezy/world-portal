# Agent Guidelines & Rules

## 1. Questions & Information Requests
- When a question is asked, answer it directly and completely without making any code changes.

## 2. Code Modifications & Prior Approval
- Every code change must be explained first, including what files will be modified and why.
- Always obtain explicit user approval before making any code or file modifications.

## 3. Mandatory Testing
- Automated/manual tests must be executed and verified for every bug fix and feature implementation before concluding work.
